# 智链盾 IntentShield

面向智能体执行风险的运行时安全管控平台。

## 核心理念

智能体可以拥有规划自主权，但不拥有无限执行权。

智链盾以「拦截式」架构部署在智能体与业务工具之间，智能体的每一次工具调用必须先经安全网关过闸审查，
得到放行决策后才会真正执行。

## 主要能力

- **四道防线**：看见（轨迹采集）→ 看懂（任务一致性研判）→ 核准（交叉验证）→ 拦住（策略执行）
- **五因子风险评分**：意图风险 0.25 + 意图漂移 0.25 + 动作风险 0.20 + 上下文失配 0.15 + 权限风险 0.15
- **L0-L3 动态授权**：自主放行 / 加强核验 / 限权确认 / 执行前阻断
- **凭证注入**：智能体不持有真实 API Key，改用占位符经网关代理注入
- **网络出口管控**：所有出站请求经白名单过滤，防止提示注入诱导外联
- **双组对照实验**：受控组（网关过闸）与对照组（只记录不拦截）同任务对比

## 技术栈

纯 Python 标准库 + SQLite，零第三方依赖。运行：`python app.py`

## 部署

支持 Docker 一键部署（见 `Dockerfile`）。服务监听 `PORT` 环境变量指定的端口，
未设置时默认 8800。可部署到 Render、Koyeb 等支持 Docker 的平台。

## 目录结构

```
app.py              平台主程序（HTTP 服务 + 全部 API 端点）
gateway_core.py      安全网关内核（注册/过闸/评分/决策）
static/index.html    单页管理界面（无框架，原生 JS）
real_agent/          真实大模型接入层（DeepSeek ReAct Agent）
  ├─ llm_agent.py    LLM Agent 主循环（凭证注入模式）
  ├─ is_client.py    Agent 侧 SDK（fail-closed 重试）
  ├─ sandbox.py      工具沙箱（真实文件库 + SQLite 业务库）
  ├─ fs_lab_agent.py FS 越权实验专用 Agent
  └─ planner.py      确定性规划器（对照基线）
tests/               单元测试（凭证注入 + 网络出口管控）
```
